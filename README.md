# e-plantShopping

## Project Overview

e-plantShopping is a modern React-based web application designed to provide users with a simple and engaging online plant shopping experience. The application enables customers to browse a collection of indoor and outdoor plants, view product information, add plants to a shopping cart, and manage their shopping selections before checkout.

This project demonstrates the use of React components, state management, routing, and responsive user interface design while following best practices for front-end web development.

## Features

* Browse a wide variety of plants
* View detailed plant information
* Add and remove plants from the shopping cart
* Update cart items dynamically
* Responsive and user-friendly interface
* Component-based architecture using React

## Technologies Used

* React
* JavaScript (ES6+)
* HTML5
* CSS3


## Getting Started

1. Clone the repository.
2. Install the project dependencies.
3. Start the development server.
4. Open the application in your browser to explore the plant shopping experience.

## Purpose

This project was developed as part of a coding assignment to demonstrate front-end development skills, React fundamentals, and the implementation of an interactive e-commerce application.
